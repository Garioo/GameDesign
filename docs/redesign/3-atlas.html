Concept 3 · Atlas
  • The canvas is the whole app. Pages, sketches, notes and the plan live on one surface, and you fly between places (keys 1, 2, 3, 0).
  • The Gantt is a rail laid on the floor. Drag tokens to change dates. Dashed threads show which page each task comes from.
